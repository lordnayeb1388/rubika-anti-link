# ربات ضدلینک روبیکا

یک ربات ساده و سبک برای روبیکا با Python و کتابخانه [Rubka](https://pypi.org/project/rubka/) که لینک‌های ارسال‌شده در گروه را شناسایی و حذف می‌کند.

## امکانات

- تشخیص `https://`، `http://` و `www.` در پیام‌های متنی (حتی اگر بدون فاصله به متن چسبیده باشند)
- تشخیص آدرس‌های بدون پیشوند مثل `example.com` یا `rubika.ir/xxxx` (قابل خاموش شدن)
- تشخیص لینک‌های مخفی پشت متن (در حد اطلاعاتی که API در metadata پیام می‌دهد)
- مقابله با کاراکترهای نامرئی و نیم‌فاصله‌ای که وسط لینک گذاشته می‌شود
- حذف خودکار پیام لینک‌دار و ارسال پیام کوتاه: `⚠️ ارسال لینک در این گروه مجاز نیست.`
- عدم حذف پیام‌های عادی
- چند مدیر مجاز (`ADMIN_IDS`)
- روشن/خاموش کردن ضدلینک برای هر گروه به‌صورت مستقل (ذخیره در SQLite)
- تلاش مجدد خودکار هنگام خطای شبکه و اتصال مجدد هنگام قطع شدن
- اگر ربات دسترسی حذف پیام نداشته باشد، به‌جای حذف فقط یک هشدار می‌دهد (حداکثر هر ۱۰ دقیقه)

## دستورات (فقط مدیران مجاز، داخل گروه)

| دستور | کار |
|---|---|
| `ضدلینک روشن` | فعال‌سازی ضدلینک در همین گروه |
| `ضدلینک خاموش` | غیرفعال‌سازی ضدلینک در همین گروه |
| `وضعیت ضدلینک` | نمایش وضعیت فعلی |
| `شناسه من` | نمایش شناسه (GUID) فرستنده؛ برای همه و در هر چت کار می‌کند |

> دستورها با فاصله یا بدون فاصله (مثلاً «ضد لینک روشن») هم کار می‌کنند.

## پیش‌نیازها

- Windows 11
- Python 3.9 یا بالاتر ([python.org](https://www.python.org/downloads/)؛ هنگام نصب گزینه **Add python.exe to PATH** را بزنید)
- یک ربات روبیکا و توکن آن از ربات رسمی `@BotFather` در روبیکا

## نصب و اجرا (Windows 11)

در پوشه پروژه، PowerShell یا Command Prompt را باز کنید:

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
notepad .env
```

> اگر PowerShell هنگام فعال‌سازی خطای Execution Policy داد، از Command Prompt (cmd) استفاده کنید یا یک‌بار این دستور را اجرا کنید:
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

داخل `.env` مقدار `BOT_TOKEN` را بنویسید. سپس:

```bat
python main.py
```

## راه‌اندازی در گروه

1. ربات را به گروه اضافه کنید.
2. ربات را **مدیر گروه** کنید و دسترسی **حذف پیام** را به آن بدهید (بدون این دسترسی نمی‌تواند پیامی حذف کند).
3. شناسه خودتان را بگیرید: در چت خصوصی با ربات یا داخل گروه بنویسید `شناسه من`. ربات شناسه‌ای مثل `u0AbCd...` برمی‌گرداند.
4. شناسه را در `.env` بنویسید (چند مدیر با کاما جدا شوند):

   ```
   ADMIN_IDS=u0AAAAAAAA,u0BBBBBBBB
   ```

5. ربات را دوباره اجرا کنید و در گروه `وضعیت ضدلینک` را بفرستید.

## تنظیمات (.env)

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `BOT_TOKEN` | توکن ربات (الزامی) | — |
| `ADMIN_IDS` | شناسه مدیران مجاز، با کاما جدا شوند | خالی |
| `DB_PATH` | مسیر فایل SQLite | `antilink.db` |
| `DEFAULT_ENABLED` | وضعیت ضدلینک در گروه‌های تنظیم‌نشده | `true` |
| `EXEMPT_ADMINS` | پیام مدیران حتی با لینک حذف نشود | `true` |
| `BLOCK_BARE_DOMAINS` | تشخیص `example.com` بدون http/www | `true` |
| `LOG_LEVEL` | سطح لاگ (`INFO`، `DEBUG`، ...) | `INFO` |

## نکات و محدودیت‌ها

- ربات از روی نتیجه تلاش برای حذف تشخیص می‌دهد که دسترسی دارد یا نه؛ در مستندات Rubka روشنی برای بررسی پیشینِ دسترسی ربات پیدا نشد.
- مدیران مجاز در `ADMIN_IDS` تعریف می‌شوند (نه بر اساس مدیر بودن در گروه)، چون در مستندات Rubka متدی برای پرسیدن لیست مدیران گروه پیدا نشد.
- لینک داخل کپشن عکس/فایل بررسی نمی‌شود؛ فقط متن پیام و metadata پیام.
- این پروژه با ربات واقعی روبیکا آزمایش نشده است؛ منطق تشخیص لینک و جریان کار با تست خودکار و یک شبیه‌ساز Rubka بررسی شده. پس از اولین اجرا، ساختار پاسخ API را در لاگ‌ها بررسی کنید.
- اگر ربات پیام‌های گروه را دریافت نمی‌کند، مطمئن شوید مدیر گروه است و برنامه در حال اجراست.

## آپلود در GitHub (مرحله‌به‌مرحله)

1. [Git for Windows](https://git-scm.com/download/win) را نصب کنید و در [github.com](https://github.com) حساب بسازید.
2. در GitHub روی **New repository** بزنید، نام `rubika-anti-link` را بدهید و **بدون** افزودن README یا .gitignore بسازید (Create repository).
3. یک‌بار هویت Git را تنظیم کنید:

   ```bat
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

4. در پوشه پروژه دستورهای زیر را اجرا کنید:

   ```bat
   git init
   git add .
   git status
   ```

   **مهم:** در خروجی `git status` نباید `.env` یا فایل `.db` دیده شود. فقط `.env.example` باید باشد.

   ```bat
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/USERNAME/rubika-anti-link.git
   git push -u origin main
   ```

   به‌جای `USERNAME` نام کاربری خود را بنویسید. هنگام push پنجره ورود GitHub باز می‌شود.
5. صفحه مخزن را رفرش کنید؛ فایل‌ها باید آنجا باشند.
6. اگر به‌اشتباه توکن را آپلود کردید، فوراً در `@BotFather` توکن جدید بگیرید؛ حذف فایل از گیت‌هاب کافی نیست چون در تاریخچه می‌ماند.

**روش جایگزین بدون Git:** در صفحه مخزن **Add file → Upload files** را بزنید و فایل‌های پروژه را (به‌جز `.env` و `.venv`) بکشید و رها کنید. فایل ZIP را قبلاً از حالت فشرده خارج کنید.
